## Design Context

### Users
Learners picking a quiz topic (business, medicine, music) and recruiters/visitors scanning a personal tool portfolio. Job to be done: find a topic fast, start a quiz; secondary: see who built it without that competing with the quiz list.

### Brand Personality
Practical, calm, clear. Confidence without flash. Personal tool, not a startup landing page.

### Aesthetic Direction
Elevated utility — intentional light and dark themes, refined typography, soft tinted neutrals (slate/teal), no default Bootstrap jumbotron look. Anti-references: generic template gray boxes, emoji-heavy chrome, flashy badge clusters, purple/neon AI aesthetics.

### Design Principles
1. Quiz selection is the hero; branding is clear but credits stay out of the way.
2. Progressive disclosure — credits and secondary links expand on demand.
3. Calm hierarchy: one title, one short line of support, then the list.
4. Respect light and dark via system preference with tinted surfaces, not flat gray/white.
5. Motion only for state (expand/collapse, hover) — no decorative noise.
